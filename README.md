Active Directory Administration Lab 

A hands-on Active Directory administration project using Windows Server to build, configure, secure, and manage a domain environment using Active Directory Domain Services (AD DS).

1. Domain and Active Directory Configuration

- Installed and configured Active Directory Domain Services (AD DS).
- Promoted Windows Server to a Domain Controller.
- Configured DNS to support domain name resolution and Active Directory services.
- Created and configured the "martintech.test" domain.
- Explored domain administration and centralized management of network resources.

2. User and Computer Account Management

- Created and managed domain user accounts.
- Joined computers to the domain.
- Created and managed computer accounts in Active Directory.
- Configured which computers users are permitted to log on to.
- Managed user account lockouts and unlocks.
- Reset user passwords and managed account status.
- Configured user logon hours to restrict access to specified times.

3. Organizational Units (OUs) and Group Management

- Created and organized departmental Organizational Units (OUs).
- Created and managed security groups for access control.
- Organized users and computer accounts according to departmental requirements.
- Used OUs to structure Active Directory objects and simplify administration.

4. Group Policy Management

- Created and configured Group Policy Objects (GPOs).
- Linked GPOs to the appropriate OUs.
- Applied policies to manage users and computers centrally.
- Configured domain password policies and account lockout policies.
- Explored how Group Policy settings affect users and computers.
- Practised troubleshooting Group Policy application and configuration issues.

5. Shared Folders and Access Control

- Created and configured shared folders for departmental access.
- Configured NTFS permissions to control access to files and folders.
- Configured share permissions for network access.
- Used security groups to assign and manage folder access.
- Applied the principle of least privilege by granting users only the permissions required for their roles.

6. Password and Account Security

- Configured password policies to enforce password requirements.
- Configured account lockout policies to help protect against repeated failed logon attempts.
- Managed password resets, account lockouts, and user account restrictions.
- Applied user logon hours and computer logon restrictions.
- Explored security practices for protecting domain user accounts.

7. Delegation of Administration

- Explored the delegation of administrative tasks within Active Directory.
- Delegated selected permissions over specific OUs.
- Practised assigning controlled administrative privileges without granting Domain Admin access.
- Explored how delegated users can perform authorized tasks, such as resetting passwords and unlocking user accounts.
- Applied the principle of least privilege to administrative access.

8. Active Directory Auditing and Monitoring

- Explored Active Directory auditing and security monitoring.
- Examined Windows Event Viewer and relevant security logs.
- Investigated events related to account logons, failed logon attempts, account lockouts, and password changes.
- Explored how auditing can help identify suspicious activity and support troubleshooting.
- Investigated the importance of monitoring administrative actions and changes to Active Directory objects.

9. Active Directory Backup and Recovery

- Explored Active Directory backup and recovery procedures.
- Installed and configured Windows Server Backup.
- Investigated System State backups and their importance in protecting Active Directory data.
- Explored backup storage options, including external storage devices.
- Examined recovery considerations for domain controllers and Active Directory services.
- Practised understanding backup verification, disaster recovery planning, and the importance of storing backups separately from the server being protected.
